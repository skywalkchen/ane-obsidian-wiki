Cardiac Physiology

心室肌細胞動作電位（Ventricular Myocyte Action Potential）

五個時相

時相 名稱 主要離子流
Phase 0 快速去極化（Rapid depolarization） Fast Na⁺ channel 開放 → 大量 Na⁺ 內流
Phase 1 早期快速復極化 Na⁺ channel 關閉；Transient outward K⁺（Ito） 外流
Phase 2 平坦期（Plateau） L-type Ca²⁺ channel 開放（內流）↔ 慢 K⁺ 外流 保持平衡
Phase 3 快速復極化 L-type Ca²⁺ channel 關閉；IKr（Rapid K⁺）外流為主
Phase 4 靜止膜電位 心室肌：靜止（-90 mV）；竇房結：自動去極化（If, "pacemaker current"）
❗ 重要

Phase 2（平坦期） 決定了心肌不應期（refractory period）的長度；延長 Phase 2（如 Class III 抗心律不整藥 amiodarone）可延長 QT interval。

竇房結（SA node）vs 心室肌的差異

特性 SA Node 心室肌
靜止膜電位 -60 mV（不穩定，自動去極化） -90 mV（穩定）
Phase 0 去極化速率 慢（L-type Ca²⁺ channel） 快（Fast Na⁺ channel）
起搏電流 If（Funny current，HCN channel） 無
傳導速度 慢 快

心律不整的主要機轉

1. 自律性異常（Abnormal Automaticity）

  • 非竇房結起搏點的自律性增強 → 異位心律
  • 常見於：低血鉀、心肌缺血、catecholamine 過量

2. 觸發活動（Triggered Activity）

Early Afterdepolarization（EAD）

  • 發生於 Phase 2 或 3
  • 機轉：L-type Ca²⁺ channel 再次開放（長 QT 症候群）
  • 常見：低鉀、QT 延長藥物、心動過緩

Delayed Afterdepolarization（DAD）

  • 發生於 Phase 4
  • 機轉：Ca²⁺ 超載 → NCX（Na/Ca exchanger）去極化
  • 常見：洋地黃中毒、心衰竭、高心率

3. 折返（Re-entry）

  • 單向傳導阻滯 + 緩慢傳導路徑 → 電位在迴路中循環
  • 最常見機轉：WPW、SVT、VFIB、心房撲動

Vaughan Williams 抗心律不整藥分類

Class 機轉 代表藥物
Ia Na⁺ channel 中度阻斷 + K⁺ channel 阻斷 Quinidine、Procainamide
Ib Na⁺ channel 弱阻斷（在心室缺血組織） Lidocaine、Mexiletine
Ic Na⁺ channel 強阻斷 Flecainide、Propafenone
II β-adrenergic blocker Metoprolol、Esmolol
III K⁺ channel 阻斷（延長 Phase 3/QT） Amiodarone、Sotalol
IV Ca²⁺ channel blocker（L-type） Verapamil、Diltiazem
💡 臨床珍珠

Amiodarone 涵蓋 Class I、II、III、IV 效應，是最廣譜的抗心律不整藥，術中 VF/VT 的首選藥物（300 mg IV bolus）。

電解質對心臟的影響

電解質異常 ECG 變化 心律風險
低血鉀（< 3.0） U wave、T wave 低平、ST 壓低 EAD → Torsade de pointes
高血鉀（> 6.0） Peaked T → PR 延長 → QRS 增寬 → Sine wave VF、心臟停止
低血鈣 QT 延長 Torsade de pointes
高血鎂 PR 延長、心動過緩 心臟停止（> 15 mEq/L）
